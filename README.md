# gerador-cracha-js.

Gerador de Crachá Virtual

O objetivo desse projeto é criar um programa em HTML e JavaScript que pede algumas informações ao usuário, como nome, sobrenome e ano de nascimento. Ele também pergunta se a pessoa é aluna ativa da instituição. Com esses dados, o programa calcula a idade aproximada, conta quantas letras tem o primeiro nome e mostra tudo organizado como um crachá virtual no console do navegador.
